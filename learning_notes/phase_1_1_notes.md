### Why This Step Matters

A SOC project should be organized properly because real SOC work depends on evidence, logs, reports, screenshots, playbooks, and documentation.

### Key SOC Concepts

#### Alert

A signal generated by a SIEM or security tool when suspicious activity is detected.

#### Incident

A confirmed or suspected security event that requires investigation and response.

#### MITRE ATT&CK

A knowledge base of attacker tactics and techniques used to classify and understand cyberattacks.

#### Triage

The first-level analysis process where SOC L1 checks whether an alert is true positive, false positive, or needs escalation.
