# SentinelOps-AI Command Center

SentinelOps-AI is an AI-powered SOC L1 command center designed for SIEM alert monitoring, incident triage, MITRE ATT&CK mapping, case management, AI risk scoring, and SOAR-based response recommendation.

## Objective

To help SOC L1 analysts identify, prioritize, investigate, and respond to security alerts faster using SIEM integration, AI-assisted triage, and structured incident playbooks.

## Core Features

- Live alert dashboard
- SIEM alert ingestion
- AI risk scoring
- MITRE ATT&CK mapping
- Incident case management
- Analyst notes
- SOAR recommendation panel
- SOC report generation
- Google Colab ML training
- Emerging threat analysis
- Alert-to-incident workflow

## Initial Lab Scenarios

1. SSH brute-force detection
2. Network scanning detection
3. Suspicious privilege escalation detection

## Planned Technology Stack

- Python
- Google Colab
- FastAPI
- SQLite
- React + Vite
- Wazuh SIEM
- MITRE ATT&CK
- Machine Learning
- SOAR-style automation

## SOC L1 Learning Outcome

By building this project, the learner will understand:

- How SIEM alerts are generated
- How SOC L1 analysts triage alerts
- How to map alerts to MITRE ATT&CK
- How to calculate risk score
- How to create incident cases
- How to document investigation notes
- How AI can assist but not replace SOC analysts
